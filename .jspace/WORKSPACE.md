- Regla fija para toda ola futura: UNA sola representación de expresión — todo algoritmo nuevo se implementa sobre `Expr`/bytecode reusando `evaluate_cached` → `compile_flat_ops` → `run_opcodes_flat` (`expr.rs:1019,2256,1976`); nunca portar la `Expression` hash-consed de MathHook ni el `Expr` boxeado de MathCore (bytecode propio 87.6 ns vs 7.4 µs intérprete, `docs/profiling.md` §2.1).

- Comandos GeoGebra: todo spec visible ejecuta con su ejemplo mínimo o está pinneado como error honesto permanente/subset; nunca "no reconocido"/"no implementado" silencioso (`execution_smoke.rs`).
